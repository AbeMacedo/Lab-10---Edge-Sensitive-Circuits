## Lab Questions

### What is difference between edge and level sensitive circuits?
The difference between edge and level sensitive ciruits are that edge sensetive
ones can change or activate their singals only during transtioning periods
from 1 to 0 or 0 to 1 signals. Where as a level senstive circuit change or activate 
their signals during either 1 or 0 signals.

### Why is it important to declare initial state?
Becuase the circuit needs a starting state in order to function properly and
work how it suppose to. Since the opertion of a something like a sequential flip
flop circuit can depend on the first state.

### What do edge sensitive circuits let us build?
Edge senstive circuits let use build memory storing and sequential circuits,
as well as different types of flip flop circuits.
